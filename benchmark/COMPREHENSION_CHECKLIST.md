# AVGL comprehension checklist

Use this checklist when testing a new AVGL projection against this repository. A viewer should be able to answer these questions without reading the implementation first.

- Who is the acting agent?
- Which context does it read?
- Where is the refund proposal produced?
- Which technical capability exists?
- Where is the authority boundary?
- Which refunds are automatic under the default policy?
- Which value is overridden for VIP customers?
- Where can external state actually change?
- Why is a provider receipt not yet a verified outcome?
- Where is the outcome independently checked?
- Which relation is inheritance and which is mere containment?
- What remains unknown if AVGL has insufficient evidence?

## Pass condition

A projection is useful when a new viewer can identify actor, context, decision point, capability, authority, effect path, verification path, inheritance, override, provenance, and downstream impact without relying on file naming alone.
